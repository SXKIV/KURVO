# KURVO

**KURVO** (nombre temporal) es la página web del colectivo de arte impreso **KURVOZINE**.

## ¿Qué queremos hacer?

- **Ahora:** una página que se sienta como un **fanzine digital** de KURVOZINE: hecha a mano, imperfecta a propósito, con texturas de fotocopia y collage, y que quien la visite pueda intervenir (cambiar el papel, la tinta, el orden…).
- **Más adelante:** un espacio exclusivo para artistas, donde cada perfil se pueda diseñar casi por completo, sin una plantilla fija.

La idea central: KURVOZINE defiende el papel frente a la saturación digital, así que la web **no puede ser "una web más"**. Tiene que traer lo táctil, lo irrepetible y lo colectivo del zine a la pantalla.

## ¿Qué hay en esta carpeta?

- `CLAUDE.md`: instrucciones y contexto para Claude, la IA que nos ayuda a construir el sitio.
- `docs/textos/`: textos del colectivo (historia, manifiesto, contenido de las páginas).
- `docs/decisiones.md`: registro de las decisiones que toma el equipo.
- `docs/referencias/`: capturas e ideas que nos inspiran.

## ¿Cómo se trabaja?

Este proyecto vive en un **repo** (repositorio: la carpeta del proyecto en GitHub, con todo su historial de cambios).

1. Cada cambio se prueba en una **rama** (una copia paralela del proyecto que no toca la versión oficial).
2. Cuando está listo, se abre un **PR** (pull request: una propuesta de cambio que el equipo revisa).
3. Si el equipo está de acuerdo, el cambio se suma a la versión oficial.

Las decisiones de estética, contenido, nombre y tecnología las toma **el equipo**: Agus, Luna, Morra, Malú y Xakal.
