# Registro de decisiones de KURVO

Aquí anotamos las decisiones importantes del equipo (estética, contenido, nombre, stack —el conjunto de tecnologías con que se construye el sitio—, etc.), para recordar **qué** decidimos, **por qué** y **quién** participó.

Cómo usarlo:

- Cada decisión nueva va **arriba** de las anteriores, con el número siguiente.
- Copia la plantilla de abajo y rellénala.
- Si una decisión cambia más adelante, no la borres: márcala como "Reemplazada por #N" y escribe la nueva.

---

## Plantilla

```markdown
## #N — Título corto de la decisión

- **Fecha:** AAAA-MM-DD
- **Estado:** propuesta | aceptada | reemplazada por #N | descartada
- **Quiénes participaron:** (pseudónimos)

**Contexto:** ¿Qué problema o pregunta teníamos?

**Opciones consideradas:**
1. Opción A: ventajas / desventajas.
2. Opción B: ventajas / desventajas.

**Decisión:** ¿Qué elegimos?

**Por qué:** Las razones principales.

**Consecuencias:** ¿Qué cambia o qué queda pendiente a partir de esto?
```
