# Referencias

Carpeta para guardar capturas, escaneos y análisis de sitios o materiales que nos inspiran.

- De cada referencia extraemos **principios** (qué nos gusta y por qué), nunca copiamos diseños ni recursos.
- Las plataformas del mercado (Behance, ArtStation, Tumblr, etc.) se estudian para **diferenciarnos**, no para imitarlas.
- Nombra los archivos de forma descriptiva, por ejemplo `neocities-kurvozine-analisis.md` o `escaneo-vol8-textura.jpg`.
