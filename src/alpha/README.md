# Piloto alpha

> ⚠️ **Prototipo para presentar al equipo. Nada está decidido.** Ver la sección "Pilotos" de `CLAUDE.md`.

Una página estática (HTML, CSS y JS sin librerías) que presenta KURVO como fanzine: portada, manifiesto, historia y volúmenes, y equipo.

**Cómo verla:** abre `index.html` con doble clic en cualquier navegador. No necesita instalar nada.

**Qué se puede probar:**

- **Cambiar la tinta:** las tres direcciones del borrador de `DESIGN.md` (Fotocopia de facultad, Riso de correspondencia, Herbario sensorial). Todas usan las mismas variables CSS (los tokens de diseño: valores visuales guardados con nombre), solo cambian sus valores.
- **Derecho ↔ kurvo:** un control que endereza o tuerce todo el zine.
- **Número de ejemplar:** cada navegador recibe el suyo, como un tiraje.

La elección se guarda solo en el navegador de quien visita (almacenamiento local).

**Textos:** todos son borrador, armados desde `docs/textos/kurvozine_contexto.md`. Los marcados `[… PENDIENTE — nombre]` esperan el texto real del colectivo.

**Provisional y para discutir:** las tres direcciones cargan sus tipografías a la vez desde Google Fonts (más peso del que tendría la versión final, que usaría una sola dirección).
